## ⚡ 30-Second Setup

```bash
# 1. Backend (Terminal 1)
cd backend
npm install
# Create .env file with MONGO_URI and JWT_SECRET
npm run dev

# 2. Frontend (Terminal 2)
cd frontend
npm install
# Create .env file with REACT_APP_API_URL=http://localhost:5000
npm start

# 3. Seed Database (Terminal 3)
cd backend
npm run seed

# Done! Open http://localhost:3000
```
